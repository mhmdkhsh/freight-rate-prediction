# Freight Rate Prediction

Machine learning solution for the Freight Rate Prediction assessment.

## Overview

The objective is to predict the posted freight rate for future loads using historical load data.

The final solution uses CatBoost regression with nonlinear distance features and equipment interaction features.

## Validation Strategy

An expanding time-based validation strategy was used because the validation period occurs after the training period.

Fold 1: Train January-June 2025, validate July 2025.
Fold 2: Train January-July 2025, validate August 2025.
Fold 3: Train January-August 2025, validate September 2025.
Fold 4: Train January-September 2025, validate October 2025.

## Feature Engineering

The final model uses distance, weight, equipment, pickup and delivery locations, geographic differences, nonlinear distance transformations, distance bins, equipment-distance interactions, weight-distance interactions, market index, quote signal, and calendar features.

Missing numeric values were handled using training-set medians.

## Model Development

A baseline CatBoost model achieved a mean validation RMSE of approximately 631.0.

Route-history target statistics were tested but reduced performance.

A rate-per-mile modeling approach was also tested and achieved a mean RMSE of approximately 638.1.

The final nonlinear distance and equipment interaction approach achieved the best mean validation RMSE of 629.67.
